HUNTER'S ARCHIVE — DEMO

CARA PAKAI
1. Ekstrak ZIP.
2. Letakkan file gambar di folder yang sama dengan index.html, style.css, dan script.js.
3. Gunakan nama file gambar persis seperti daftar berikut:
   jyuratodus.jpg
   great-jagras.jpg
   pukei-pukei.jpg
   tobi-kadachi.jpg
   rathalos.jpg
   diablos.jpg
   anjanath.jpg
   zinogre.jpg
   nergigante.jpg
   kushala-daora.jpg
   teostra.jpg
   fatalis.jpg
4. Buka index.html dengan VS Code dan jalankan menggunakan Live Server.
5. Untuk GitHub Pages, upload seluruh file ke repository yang sama.

Jika foto kamu berformat PNG atau WebP, ubah nilai `file` monster terkait di script.js agar cocok dengan nama dan ekstensi file sebenarnya.
Semua file gambar berada di root folder; tidak ada folder assets.
